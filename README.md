## 📖 About the Project

**छठ पूजा (Chhath Puja)** is one of the most sacred, ancient, and austere Vedic festivals celebrated across Bihar, Jharkhand, Eastern Uttar Pradesh, Nepal, and across the global Indian diaspora. Spanning four days of pure devotion—*Nahay Khay, Kharna, Sandhya Arghya, and Usha Arghya*—the festival is deeply intertwined with divine folk music that brings peace, reverence, and spiritual awakening.

This web application was envisioned and created by **Uday Raj** to provide devotees with an authentic, spiritually immersive, and technologically modern audio-visual platform. Unlike standard music apps with cluttered interfaces and mismatched song titles, this application ensures **100% verified artist-voice accuracy**, cinematic ambient ghat environments, and fluid devotional controls.

---

## 🌟 Project Description

The **Chhath Puja Sacred Devotional Music Player** is a single-page progressive web application built with pure Vanilla Web Technologies (HTML5, modern CSS3 Glassmorphism, and ES6+ JavaScript) combined with the official **YouTube IFrame API**.

### Core Highlights:
- **Zero Mismatch Audio Engine**: Every single song in the playlist has been individually cross-verified via YouTube oEmbed to guarantee that the singer displayed (Sharda Sinha, Pawan Singh, Khesari Lal Yadav, Anuradha Paudwal, Shilpi Raj, etc.) is the genuine singer performing in the audio and video.
- **Cinematic Atmosphere**: Features dynamic particle embers, floating celestial diyas, golden sunrays, and realistic water rippling reflections that adapt dynamically to daytime and nighttime rituals.
- **Dual Sacred Ambiance**: Seamlessly toggle between **Morning View (उषा अर्घ्य - Dawn)** and **Evening View (संध्या अर्घ्य - Sunset Ghats with glowing earthen lamps)**.
- **Dual Visualization Modes**: Enjoy the rhythmic spinning **Sacred Brass Diya Vinyl Disc** or switch instantly to the embedded **Full HD YouTube Video stream** right inside the player card.
- **Download & Offline Capabilities**: Devotees can easily download devotional tracks or save them directly into their in-browser offline library.

## ✨ Key Features

### 1. 🎵 100% Authentic & Verified Songs Catalog
- Contains **120+ top-rated sacred Chhath bhajans, geets, and aartis**.
- No placeholder tracks, duplicate IDs, or mismatched singer names.
- Complete coverage of legendary classics from Padma Bhushan **Sharda Sinha** and Padma Shri **Anuradha Paudwal**, alongside modern blockbusters by **Pawan Singh**, **Khesari Lal Yadav**, **Shilpi Raj**, **Pramod Premi**, **Aashish Yadav**, **Anu Dubey**, **Kalpana Patowary**, and **Manoj Tiwari**.

### 2. 🌅 Morning vs 🌆 Evening Ghat Themes
- **Morning Mode (उषा अर्घ्य)**: Golden sunrise hues, radiant solar glow, morning river mist, and uplifting chants greeting Lord Surya (*Uga Hai Suraj Dev*).
- **Evening Mode (संध्या अर्घ्य)**: Deep twilight crimson and twilight blues, hundreds of floating glowing diyas, incense smoke auroras, and tranquil evening prayers.

### 3. 🪔 Sacred Diya Disc & 📺 HD Video Switcher
- **Sacred Diya Mode**: An ornate sacred brass diya with a flickering sacred flame seated on a rotating prayer disc that animates in sync with playback.
- **Video Mode**: Watch official devotional video clips directly in high definition with 1-click toggling.

### 4. 👁️ Modular Hide & Show System
- **Player Card Toggle**: Hide the main player card (`H`) to view the beautiful scenic Ghat background unimpeded.
- **Playlist Toggle**: Hide or expand the song list (`P`) for a distraction-free experience.
- **Floating Jewel Restorers**: Sleek floating pills allow 1-click restoration of hidden panels.
- **Cinema / Zen Mode (`Z`)**: Hides all user interface components for peaceful meditation and aarti background display.

### 5. 📥 Complete Song Download & Offline Library
- **Download Modal (`D`)**: Easy direct access to download MP3 Audio (320kbps) or 1080p HD Video.
- **Offline Save**: Store favorite songs into local browser cache to listen anytime.

### 6. 🔍 Real-Time Search & Categorized Filters
- Search instantly by singer name, song title, lyrics keyword, or category.
- Categorized tabs:
  - 🕉️ **All (सभी गीत)**
  - ❤️ **Favorites (पसंदीदा)**
  - 🌅 **Arghya / Sandhya Ghat (अर्घ्य एवं संध्या)**
  - ☀️ **Morning Surya (उषा अर्घ्य)**
  - 🎋 **Bahangi (दउरा एवं बहंगी गीत)**
  - 🪔 **Devotional (पारंपरिक भक्ति)**
  - 🎶 **Modern (नवीन भक्ति संग्रह)**

### 7. 🔊 Pro Devotional Audio Engine
- Live audio visualizer bars responsive to playback state.
- Seekable interactive waveform scrub bar with elapsed & remaining time indicators.
- Volume slider with persistent memory and 1-click mute/unmute.
- Loop modes: Repeat All, Repeat One, and Loop Off.
- Smart Shuffle mode for endless devotional playlists.

## 🛠️ Technology Stack

- **Frontend Core**: Semantic HTML5 with accessibility ARIA tags
- **Styling Architecture**: Pure Vanilla CSS3 (Custom Glassmorphism, CSS Custom Properties, Multi-layer Gradients, Hardware-accelerated 3D transforms)
- **Scripting & Engine**: Modern ES6+ JavaScript (Async/Await, Custom Event Listeners, State Management)
- **Audio Streaming API**: YouTube IFrame Player API
- **Particle System**: HTML5 2D Canvas Particle Engine for glowing embers and water sparks
- **Local Persistence**: Browser `localStorage` for volume, favorites, view mode, and player visibility
- **Local Server**: Native Node.js HTTP static server (`server.mjs`)

## 🚀 Quick Start / Installation

Follow these steps to run the application locally on your machine:

### Prerequisites
- [Node.js](https://nodejs.org/) (Version 16 or higher installed)
- Any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari)

### 1. Clone the Repository
```bash
git clone https://github.com/udayraj7366/chhath-puja-music.git
cd chhath-puja-music
```

### 2. Start the Local Server
```bash
node server.mjs
```

### 3. Open in Browser
Visit the following URL in your web browser:
```
http://localhost:3000/
```

Enjoy non-stop, divine Chhath Puja bhajans with zero interruptions!

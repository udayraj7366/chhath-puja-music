# 🪔 छठ पूजा • Chhath Puja Devotional Music Player

> **Dedicated with sacred faith & devotion by [Uday Raj](https://github.com/udayraj7366)**  
> 🌟 *A cinematic, ultra-modern single-page devotional music experience celebrating the holy festival of Chhath Puja.*

---

## ✨ Features

- **500 Top Sacred Geets & Bhajans**:
  - Iconic timeless tracks by **Sharda Sinha**, **Pawan Singh**, **Khesari Lal Yadav**, **Pramod Premi**, **Aashish Yadav**, **Shilpi Raj**, **Anu Dubey**, **Kalpana Patowary**, **Anuradha Paudwal**, and more.
  - Specific tracks: *"Kakra Khatir Karab Chhath Puja"*, *"Saiya Arab Gaile Na"*, *"Pahile Pahil Hum Kailin"*, *"Kelwa Ke Paat Par"*, *"Chhathi Maiya Ke Baratiya"*, etc.
- **🌅 Morning vs 🌆 Evening Ghat Themes**:
  - Interactive toggle for **Usha Arghya** (Golden Dawn) and **Sandhya Arghya** (Dusk Twilight with floating lamps).
- **🪔 Sacred Diya Disc & 📺 HD Video Embed**:
  - Rotating vinyl disc featuring the sacred glowing deepak.
  - 1-click switch to full HD YouTube Video stream.
- **📥 Complete Song Download System**:
  - Download high-quality MP3 audio (320 kbps) or full HD video.
  - Save songs to in-app offline library for playback without internet.
- **👁️ Hide & Show System**:
  - Independent hide/show buttons for both Player Card (`H`) and Playlist (`P`).
  - Floating jewel pill buttons to restore instantly.
  - Cinema / Zen Mode (`Z`) to hide all UI and enjoy pure scenic Ghat views.
- **⌨️ Rich Keyboard Shortcuts**:
  - `Space`: Play / Pause
  - `→` / `←`: Next / Previous song
  - `↑` / `↓`: Volume Up / Down
  - `M`: Mute / Unmute
  - `F`: Favorite track
  - `D`: Download song modal
  - `H`: Hide / Show player
  - `P`: Hide / Show playlist
  - `T`: Toggle Morning / Evening theme
  - `V`: Toggle Diya Disc / Video view
  - `Z`: Cinema / Zen mode
  - `?`: Shortcuts cheat sheet

---

## 🚀 Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/udayraj7366/chhath-puja-music.git
   cd chhath-puja-music
   ```

2. Start the local server:
   ```bash
   node server.mjs
   ```

3. Open in your browser:
   ```
   http://localhost:3000/
   ```
